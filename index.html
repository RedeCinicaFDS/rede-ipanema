Como publicar no GitHub Pages

  1. Clique em Baixar dados.json aqui em cima.
  2. Abra o repositório no GitHub e clique no arquivo dados.json.
  3. Clique em Add file → Upload files na pasta e arraste o arquivo baixado por cima.
  4. Clique em Commit changes. Em cerca de um minuto o site atualiza para todo mundo.
